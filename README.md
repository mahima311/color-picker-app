# Color Picker App

A simple React-based color picker app that lets users choose colors and see their hex codes in real-time.
Useful for designers, developers, and students.

---

## Features
- Pick colors using a color palette
- Copy hex code to clipboard
- Real-time color preview
- Responsive and easy to use

---

## How to Use

1.Clone the repository 
git clone https://github.com/mahima311/color-picker-app.git

2.Navigate into the project folder
cd color-picker-app

3.Install dependencies
npm install

4.Start the development server
npm start
5.Open in browser
The app will automatically open at http://localhost:3000
If it doesn't, open your browser and go to the above URL.
