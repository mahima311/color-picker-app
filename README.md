# Color Picker App
A simple color picker app that lets users choose colors and see their hex codes.
Useful for designers, developers, and students.
## Features
- Pick colors using a color palette
- Copy hex code to clipboard
- Real-time color preview
## How to Use
1. Open `index.html` in your browser
2. Choose a color from the palette
3. Copy the hex code using the copy button
## Technologies
- HTML
- CSS
- JavaScript
